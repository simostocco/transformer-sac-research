# Published research boundary

[simostocco/transformer-sac-research](https://github.com/simostocco/transformer-sac-research) is the public source-only repository authorized by the owner on 2026-11-18. Its initial published source snapshot was `855a22aea60f10174033d57d17c2c8e1821be4a8`, with standalone history. The operational trading repository, its 60 unpushed implementation commits and all unrelated work remain private.

[PUBLICATION_MANIFEST.csv](../PUBLICATION_MANIFEST.csv) binds the selected tree. Included content is project source, synthetic tests/example, documentation, dependency metadata and license notices. The manifest's own recursive hash is deliberately omitted. Changes must update the affected file hashes while preserving the source/data boundary.

Excluded content includes private Git ancestry and review/application material, raw logs and recordings, prices/real feature tables, symbol-level results and private benchmark figures, fitted scalers/centers, model weights, credentials, private scanner strategy and vendor headers/libraries. The public tests need no licensed feed account or SDK. The native `Sdk` abstraction is project-side code; external OpenSSL/oneMKL dependencies are not bundled or relicensed.

The owner approved MIT for the project-owned source; the NumPy BSD notice and external dependency terms remain separate. Existing vendor/venue agreements were not supplied for independent disclosure clearance. Publishing this source does not authorize adding private data, artifacts or quantitative results. Public API documentation or a derived-data label does not grant redistribution rights.

The historical Polygon credential belongs to the original private archive. Its literal and archive ancestry were absent from the initial public repository's complete history; provider-side revocation remains unverified and is a separate private follow-up. Never paste a credential into public files, issues or PRs.

Documentation/source changes are reviewed through branches and PRs. Public visibility does not authorize merging a new PR, importing private history or broadening this release boundary. The private feed/serving adapter and full trained/live reproduction remain outside this repository.
